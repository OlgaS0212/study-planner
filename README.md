# Study Planner

Study Planner är ett digitalt hjälpmedel för studenter som samlar och presenterar relevant information om kurser på ett tydligt och lättillgängligt sätt.

Appen ska hjälpa studenter att:
hitta information om kursinnehåll och kursplaner
hålla koll på deadlines, examinationer och litteratur
skapa personliga studieplaner
strukturera uppgifter
få påminnelser om viktiga datum
få bättre överblick över sina studier

## Syfte

Syftet är att göra det enklare för studenter att prioritera sina uppgifter och planera sin tid på ett effektivt sätt.
